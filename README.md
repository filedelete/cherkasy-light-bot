# Бот графіка відключень: Черкаська область

Кожні 10 хвилин перевіряє сайт Черкасиобленерго й постить у Telegram-канал (або групу) текстове повідомлення з графіком усіх черг, коли графік **з'явився** або **змінився**. Для кожної черги видно години без світла й скільки це разом; якщо графік змінився, зверху показано, які черги змінились і що саме (➖ було, ➕ стало), а ці черги позначено 🔄.
Працює безкоштовно на GitHub Actions. Дані бере через бібліотеку [ukraine-energy-monitor](https://github.com/fastiuk/ukraine-energy-monitor).

## Налаштування (≈15 хв)

1. **Бот.** У Telegram відкрийте @BotFather → `/newbot` → збережіть **токен**.
2. **Канал.** Створіть канал (або групу), додайте бота **адміністратором** з правом публікувати повідомлення.
3. **chat_id.**
   - Публічний канал: підійде `@назва_каналу`.
   - Приватний канал чи група: перешліть будь-яке повідомлення з нього боту @getidsbot і візьміть число виду `-100…`.
4. **Репозиторій.** На GitHub створіть репозиторій (публічний дає більше безкоштовних хвилин) і завантажте туди **весь вміст цієї папки**, зокрема прихованої папки `.github`.
5. **Secrets.** Repo → Settings → Secrets and variables → Actions → New repository secret:
   - `TELEGRAM_BOT_TOKEN`: токен із кроку 1;
   - `TELEGRAM_CHAT_ID`: з кроку 3 (кілька чатів через кому);
   - `ADMIN_CHAT_ID` (необов'язково): ваш особистий chat_id, щоб бот написав, якщо джерело не відповідає понад годину.
6. **Запуск.** Вкладка Actions → `check-schedule` → Run workflow. Далі він запускається сам.

Перший запуск публікує поточні графіки. Щоб цього не було, додайте в `check.yml` змінну `POST_ON_FIRST_RUN: "0"`.

## Перевірка без Telegram

```
pip install -r requirements.txt          # потрібен Python 3.13
python -m bot.demo                       # друкує приклади повідомлень у консоль
DRY_RUN=1 python -m bot.main             # справжній запит до сайту, але нічого не відправляє
```

## Якщо сайт обленерго не відкривається з GitHub

У логу Actions буде `Не вдалося отримати графік…`. Тоді запустіть той самий код на постійно ввімкненому пристрої в Україні (комп'ютер, Raspberry Pi, VPS): задайте ті самі змінні середовища й додайте в cron `*/10 * * * * cd /шлях && python -m bot.main`. Стан зберігається у `state/state.json`.

## Нотатки

- GitHub може запускати розклад із затримкою в кілька хвилин. Сповіщення це не втрачає: порівнюється з попереднім станом.
- Раз на добу бот оновлює `state/state.json`, щоб GitHub не вимкнув розклад через 60 днів без активності.
- Графіки належать операторам системи розподілу.
